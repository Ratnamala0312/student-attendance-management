# Student Attendance Management System

## 📌 Project Description
A simple web-based Student Attendance Management System developed using HTML, CSS, and JavaScript.

## 🚀 Features
- Add student attendance
- Select attendance status (Present/Absent)
- View attendance records
- Delete attendance records
- Display Total, Present, and Absent counts
- Store attendance data using Local Storage

## 🛠️ Technologies Used
- HTML
- CSS
- JavaScript
- Local Storage

## 📂 Project Files
- index.html - Main webpage
- style.css - Styling
- script.js - Application functionality
